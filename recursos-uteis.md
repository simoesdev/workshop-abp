# Recursos Úteis para o Workshop

Este ficheiro reúne modelos, checklists e ideias práticas para apoiar a utilização de IA em pequenos negócios, empreendedorismo, freelancing e equipas comerciais.

A ideia é simples: começar pequeno, testar com segurança, rever sempre os resultados e só depois automatizar.

---

## 1. Checklist antes de usar IA no negócio

Antes de usar ChatGPT, Claude, Perplexity, Copilot, Gemini ou outra ferramenta semelhante, confirma:

* Sei claramente o que quero obter.
* Tenho contexto suficiente para dar ao modelo.
* Não estou a inserir passwords, chaves API, dados bancários ou dados pessoais sensíveis.
* Sei que a resposta pode conter erros.
* Vou rever o resultado antes de usar.
* Vou validar informação legal, financeira, fiscal ou técnica com profissionais qualificados.
* Não vou copiar a resposta sem adaptar ao meu negócio.

---

## 2. Checklist para um bom prompt

Um bom prompt deve responder a estas perguntas:

* Quem deve ser o assistente?
* Qual é a tarefa concreta?
* Qual é o contexto do negócio?
* Quem é o público-alvo?
* Que tom deve usar?
* Que formato deve entregar?
* Que limites deve respeitar?
* O que deve fazer quando faltar informação?

Modelo rápido:

```text
Actua como [papel].
O meu negócio é [descrição].
O público-alvo é [descrição].
Quero [objetivo].
Responde em português de Portugal, com tom [tom].
Entrega no seguinte formato: [formato].
Não faças [limites].
Se faltar informação, faz perguntas antes de responder.
```

## 4. Modelo de FAQ comercial

Usa este modelo para criar um documento simples que ajude a IA a responder de forma mais consistente.

```text
Pergunta 1:
[Qual é a pergunta frequente?]

Resposta aprovada:
[Resposta curta e clara]

Notas internas:
[O que a equipa deve saber, mas que talvez não deva ser enviado ao cliente]

---

Pergunta 2:
[Qual é a pergunta frequente?]

Resposta aprovada:
[Resposta curta e clara]

Notas internas:
[O que a equipa deve saber]
```

Exemplos de perguntas úteis:

* Quanto custa?
* Quanto tempo demora?
* O que está incluído?
* O que não está incluído?
* Como funciona o processo?
* Que garantias existem?
* Como posso marcar uma reunião?
* Que informação precisam de mim para começar?

## 5. Modelo de prompt mestre para um assistente de follow-up

```text
És um assistente de follow-up comercial para [nome do negócio].

Objetivo:
Criar rascunhos de email para leads e clientes interessados.

Tom:
Profissional, simples, próximo e sem pressão comercial.

Regras:
- Escrever em português de Portugal.
- Não inventar preços, prazos, descontos ou condições.
- Não assumir que o cliente já decidiu comprar.
- Não enviar mensagens finais sem revisão humana.
- Quando faltar informação essencial, pedir esclarecimento.

Formato de saída:
Assunto:
Email:
Próxima ação sugerida:
Risco ou observação:

Antes de terminar, verifica se:
- A mensagem tem objetivo claro.
- O tom está adequado.
- Não existem promessas não confirmadas.
- A chamada para ação é simples.
```

## 6. Checklist para revisão humana antes de enviar

Antes de enviar um email, proposta, resposta a cliente ou conteúdo gerado por IA, confirma:

* O nome do cliente está correto.
* O produto ou serviço mencionado está correto.
* Não há preços inventados.
* Não há prazos inventados.
* Não há descontos não aprovados.
* O tom está adequado ao destinatário.
* A mensagem não parece demasiado artificial.
* A chamada para ação é clara.
* Não contém informação confidencial desnecessária.
* Está escrito em português de Portugal, se esse for o objetivo.

## 7. Checklist para automações com IA

Antes de ativar uma automação com IA, confirma:

* O trigger está bem definido.
* Os dados de entrada são os mínimos necessários.
* Existe filtro para evitar casos errados.
* O prompt tem regras claras.
* O output tem formato fixo.
* Existe revisão humana antes de enviar para clientes.
* Foram testados exemplos bons, maus e incompletos.
* Existe forma de parar a automação rapidamente.
* Existe registo do que foi gerado.
* A automação não usa dados sensíveis sem necessidade.

## 8. Ideias simples de automação para pequenos negócios

### Follow-up de leads

Trigger: novo email ou formulário recebido.  
AI: cria rascunho de resposta.  
Revisão humana: validar mensagem.  
Ação final: enviar manualmente ou aprovar envio.

### Resumo diário de emails importantes

Trigger: emails recebidos durante o dia.  
AI: resume assuntos importantes.  
Ação final: enviar resumo para o empreendedor.

### Organização de pedidos em folha de cálculo

Trigger: novo formulário preenchido.  
AI: classifica tipo de pedido.  
Ação final: registar no Google Sheets, Excel ou CRM.

### Ideias semanais de conteúdo

Trigger: tarefa agendada semanal.  
AI: gera ideias de posts com base no negócio.  
Ação final: criar lista para revisão.

### Resposta inicial a perguntas frequentes

Trigger: pergunta recebida por email ou formulário.  
AI: identifica se corresponde à FAQ.  
Revisão humana: validar se a resposta está correta.  
Ação final: enviar resposta aprovada.

## 9. Estrutura recomendada para um Projeto no ChatGPT

Podes criar um Projeto por cliente, por área do negócio ou por campanha.

Exemplos:

* Marketing do negócio
* Vendas e follow-up
* Cliente A
* Produto novo
* Conteúdo para redes sociais
* Atendimento ao cliente

Dentro do Projeto, coloca:

* Ficha da empresa.
* FAQ comercial.
* Exemplos de bons emails.
* Regras de tom de voz.
* Lista de promessas proibidas.
* Templates aprovados.
* Notas sobre o público-alvo.

## 11. Erros comuns a evitar

* Pedir “faz-me um texto” sem contexto.
* Usar respostas sem revisão.
* Automatizar demasiado cedo.
* Inserir dados confidenciais sem necessidade.
* Pedir informação atual sem confirmar fontes.
* Usar a IA como se fosse consultor jurídico, fiscal ou financeiro final.
* Aceitar sugestões genéricas sem adaptar ao cliente real.
* Criar muitos assistentes sem regras claras.

---

## 12. Regra prática para começar

Começa com três passos:

1. Usa a IA manualmente para melhorar uma tarefa repetitiva.
2. Cria um template de prompt que funciona bem.
3. Só depois pensa em automatizar parte do processo.

Uma boa automação nasce de um bom processo manual. Se o processo ainda está confuso, a automação apenas torna os erros mais rápidos.
